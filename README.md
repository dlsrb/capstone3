# 저출생 정책 언론 분석
### KoELECTRA 문장 분류로 본 저출생 정책 영역별 평가와 비판 요인

> 저출생 정책 관련 뉴스 기사를 문장 단위로 **긍정 / 부정 / 중립 / 관계없음**으로 분류하고,
> 정책 영역별로 언론이 무엇을 긍정적으로 평가하고 무엇을 비판하는지 분석하여 정책 개선 방향을 도출한다.

- 과업: 문장 분류 (4-class)
- 학습 모델: KoELECTRA (수업 시간 작성 소스코드 사용)
- 데이터: 저출생 정책 관련 국내 뉴스 기사 문장 (목표 5만 건 이상)

## 1. 문제 정의 및 결론에 대한 가설

### 1.1 배경
- 우리나라는 2006년 제1차 저출산·고령사회 기본계획 이후 수백조 원 규모의 예산을 저출생 대응에 투입했다.
- 그럼에도 합계출산율은 2023년 0.72명으로 세계 최저 수준을 기록했다. <!-- 수치 출처: 통계청 인구동향조사 (확인 후 기입) -->
- 정부와 지자체는 부모급여, 육아휴직 급여 인상, 6+6 부모육아휴직제, 신생아 특례대출 등 정책을 잇달아 시행하고 있으며, 관련 보도도 꾸준히 이어지고 있다. <!-- 수집 후 실제 기사 수로 보완 -->

### 1.2 문제 정의
저출생 정책은 현금 지원, 육아휴직, 보육, 주거 등 여러 영역에 걸쳐 시행되고 있지만, **어떤 정책 영역이 긍정적으로 평가받고 어떤 영역이 어떤 이유로 비판받는지**는 체계적으로 정리되어 있지 않다.

| 현재 상황 | 한계 |
|---|---|
| 정책 평가가 개별 기사·칼럼에 흩어져 있음 | 정책 영역별로 평가를 비교하기 어려움 |
| 키워드 검색 ('저출생', '육아휴직' 등) | 정책을 **비판하는 문장**과 단순히 **소개하는 문장**을 구분하지 못함 |
| 출산율 등 결과 통계 위주의 논의 | 정책별로 **무엇이 문제로 지적되는지**는 드러나지 않음 |

**분석 목적:** 저출생 정책 관련 기사 문장을 분류하여 정책 영역별 긍정·부정 평가를 정량화하고, 주요 만족 요인과 비판 요인을 도출하여 정책 개선 방향을 제시한다.

### 1.3 가설
| 번호 | 가설 | 검증 방법 |
|---|---|---|
| H1 | 정책 영역별로 부정 평가의 비율과 주요 비판 내용이 다를 것이다 (예: 현금 지원은 실효성, 육아휴직은 사각지대) | 정책 영역 태그 × 라벨 교차 분석, 부정 문장 키워드·토픽 분석 |
| H2 | 주요 정책 시행 직후에는 해당 영역의 긍정 비율이 증가하지만, 시행 6개월 이후에는 사각지대·실효성 관련 부정 비율이 다시 증가할 것이다 | 아래 기준 시점별로 시행 전 / 직후(0~3개월) / 이후(6개월~) 긍정·부정 비율 비교 |
| H3 | 같은 정책 영역이라도 언론 성향(진보·보수·경제지)에 따라 부정 평가의 비율과 비판 내용이 다를 것이다 | 언론 성향별 라벨 분포 및 부정 문장 키워드 비교 (정부 보도자료는 비교 대상이 아닌 **기준선**으로 사용) |

**H2 기준 시점** (모든 시점은 보도자료로 확인 후 확정한다.)

| 시점 | 정책 | 정책 영역 |
|---|---|---|
| 2022.01 | 첫만남이용권 도입 | 현금 지원 |
| 2023.01 | 부모급여 도입 | 현금 지원 |
| 2024.01 | 6+6 부모육아휴직제 시행 | 육아휴직·근로시간 |
| 2024.01 | 신생아 특례대출 시행 | 주거 |
| 2024 하반기 | 늘봄학교 전국 확대 | 보육·돌봄 |
| 2025.01 | 육아휴직 급여 인상 | 육아휴직·근로시간 |

### 1.4 기대 결론
- 정책 영역별로 언론이 긍정적으로 평가하는 요인과 비판하는 요인을 정량적으로 도출한다.
- 정책 시행 전후와 언론 성향에 따라 평가가 어떻게 달라지는지 보인다.
- 분석 결과를 바탕으로 정책 영역별 개선 방향을 제시한다.
- 나아가 학습한 분류 모델을 정책 담당자의 **언론 모니터링 업무**에 활용하는 방안을 제시할 수 있다.

**출처 신뢰도 필터** (보도 내용의 사실 여부가 아니라, 출처를 확인할 수 있는지를 기준으로 함)

| 대상 | 판별 방법 | 처리 |
|---|---|---|
| 기사형 광고 | "[AD]", "협찬", "제공=", "홍보" 등 표시 | 제거 |
| 중복 기사 (보도자료 받아쓰기, 반복 송고) | 본문 유사도 기반 | 제거 (대표 1건만 유지) |
| 출처 불명 인용 | 채널·계정명 없이 "유튜브에서", "SNS에서"만 언급 | 제거 |
| 비공식 채널 영상 + 링크 끊김 | 기사 내 영상 링크 확인 (oEmbed) | 제거 |
| 커뮤니티·SNS·댓글 인용 | "온라인 커뮤니티", "누리꾼", "SNS에 올라온" 등 | 표시(flag) 후 유지 |
| 익명 출처 | "관계자에 따르면", "~라는 말이 나온다" 등 | 표시(flag) 후 유지 |
| 정정된 기사 | "바로잡습니다", "정정보도", "반론보도" | 표시(flag) 후 유지 |
| 공식 채널 영상 인용 | 정부·지자체·언론사 공식 채널 목록과 대조 | 유지 |
| 사설·칼럼·기고 | 기사 섹션 정보 | `article_type` 태그 |

- 표시(flag)된 기사는 포함했을 때와 제외했을 때의 분석 결과를 비교하여 영향 여부를 확인한다.

**정제 기준** (확정 후 보완)
- HTML 태그·특수문자 제거
- 기사 상투 문구 제거: 기자 이름·이메일, 저작권 문구("무단전재 및 재배포 금지" 등), 관련기사 목록, 사진 설명
- 5자 미만 문장 제거, 중복 문장 제거

### 2.4 데이터 이용 관련
- 일부 언론사는 기사에 "무단전재 및 재배포, AI학습 금지" 문구를 표기하고 있어, 교육 목적 사용 여부를 지도교수에게 확인할 예정이다. (확인 후 결과 기입)
- 저작권 보호를 위해 본 저장소에는 기사 원문을 공개하지 않고, **기사 URL·문장 ID·라벨**과 일부 예시만 공개한다.

## 3. 원본 데이터에 대한 EDA

> 수집 완료 후 그림과 기초통계를 채운다.

## 4. 데이터 라벨링에 대한 정의

### 4.1 라벨 정의
판단 기준: **문장에 드러난 저출생 정책에 대한 평가** (인용된 전문가·이해관계자의 평가 포함)

| 라벨 | 정의 | 예시 |
|---|---|---|
| **긍정** | 정책의 효과·성과·필요성을 긍정적으로 평가 | "육아휴직 급여 인상 후 남성 육아휴직자가 크게 늘었다" |
| **부정** | 정책의 한계·부작용·문제점을 지적하거나 비판 | "일회성 현금 지원으로는 출산 결정을 바꾸기 어렵다" |
| **중립** | 저출생 정책·현상과 관련 있지만 평가가 없는 문장 (사실, 일정, 예산, 통계, 질문, 긍정·부정이 함께 있는 양면 평가) | "정부는 내년 부모급여 예산으로 ○조 원을 편성했다" |
| **관계없음** | 기사 안에서 저출생 정책·현상과 무관한 내용의 문장 | 같은 기사 속 다른 정책·사건 이야기, 일반 경제·정치 상황 서술, 정제 후에도 남은 홍보 문장 |

※ 기자 이름, 저작권 문구, 관련기사 목록 등 상투 문구는 정제 단계(2.3)에서 제거하므로 라벨링 대상이 아니다.

### 4.2 판단 규칙 (경계 사례)
| 상황 | 규칙 | 예시 → 라벨 |
|---|---|---|
| 정부의 정책 소개 | 평가 없이 내용만 전달하면 중립 | "6+6 부모육아휴직제가 시행된다" → 중립 |
| 정부의 자화자찬 | 성과를 주장하면 긍정 | "정부는 정책 효과로 출생아가 늘었다고 밝혔다" → 긍정 |
| 저출생 현상 자체의 서술 | 정책 평가가 아니면 중립 | "합계출산율이 0.72명으로 떨어졌다" → 중립 |
| 정책 개선 요구 | 현재 정책의 부족·미흡을 지적하면 부정 | "육아휴직 사각지대를 해소해야 한다" → 부정 |
| 정책 확대 요구 | 현재 정책의 효과를 인정하며 확대를 요구하면 긍정 | "효과가 확인된 만큼 부모급여 지원 대상을 넓혀야 한다" → 긍정 |
| 확대 요구 (근거 없음) | 효과 인정이나 부족 지적 없이 확대만 요구하면 중립 | "부모급여를 더 늘려야 한다" → 중립 |
| 긍정과 부정이 공존 | 어느 한쪽이 주된 주장이 아니면 중립 (4.1 양면 평가) | "지원은 늘었지만 실효성은 의문이다" → 중립 |
| 긍정과 부정이 공존 (주장 명확) | 문장의 결론부(주로 뒤쪽)가 주된 주장이면 그 라벨 | "지원은 늘었지만, 결국 출산 결정에는 영향을 주지 못했다" → 부정 |
| 저출생과 무관한 정책 | 관계없음 | 같은 기사 내 다른 정책 이야기 → 관계없음 |

### 4.3 정책 영역 태그 (보조 라벨)
- 영역: 현금 지원 / 육아휴직·근로시간 / 보육·돌봄 / 주거 / 교육비 / 일·가정 양립 / 기타
- 키워드 규칙으로 자동 부여한 뒤, 라벨링 시 검수
- **다중 태그:** 한 문장이 여러 영역을 언급하면 모두 부여한다 (예: 육아휴직 + 일·가정 양립)
- **지시어 문장:** "이는", "해당 제도는"처럼 정책 이름 없이 지시어만 있는 문장은 ① 앞 문장의 영역 → ② 기사 제목의 영역 순으로 상속하고, 둘 다 없으면 기타로 둔다

## 7. 향후 분석 계획

### 7.1 모델 학습
- 수업 시간 작성한 KoELECTRA 소스코드로 4분류 모델 학습
- 평가 지표: Accuracy, 클래스별 Precision / Recall / F1 (특히 **부정 클래스 F1**)

### 7.2 전체 데이터 분류
- 학습한 모델로 수집한 전체 문장(5만 건 이상)을 분류
- 비교 기준으로 키워드 규칙 분류기(예: '실효성', '한계', '지적', '비판' → 부정)를 구현하고, 동일 테스트셋에서 성능을 비교하여 모델 사용의 타당성을 확인

### 7.3 정책 영역별 분석 (H1)
- 정책 영역 × 라벨 교차 분석 → 영역별 긍정·부정 비율 정량화
- 영역별 부정 문장의 주요 키워드·토픽 → 주요 비판 요인 도출
- 영역별 긍정 문장의 주요 키워드·토픽 → 주요 만족 요인 도출

### 7.4 시기별·언론 성향별 분석 (H2, H3)
- H2: 1.3의 기준 시점별로 시행 전 / 직후(0~3개월) / 이후(6개월~) 해당 영역의 긍정·부정 비율 비교
- H3: 같은 정책 영역 안에서 언론 성향(진보·보수·경제지)별 부정 비율과 비판 키워드 비교
  - 정부 보도자료는 정의상 긍정 비율이 높으므로 비교 대상이 아닌 기준선으로만 제시
- 신뢰도 표시(flag) 기사를 포함 / 제외했을 때 결과가 달라지는지 확인
- **보조 비교:** 이용 실적 통계가 있는 영역(육아휴직, 부모급여 등)은 통계 추이와 언론 평가 추이를 함께 제시
  - 출처: KOSIS, 통계청 육아휴직통계, 고용노동부 고용행정통계
  - ⚠️ 이용 실적 증가는 지원 대상 확대 등 다른 요인의 영향일 수 있으므로 인과관계로 해석하지 않음
  - ⚠️ 정책이 출산율에 미친 효과는 본 분석으로 판단할 수 없음

### 7.5 활용 방안
- **정책 개선 방향:** 영역별 비판 요인을 바탕으로 우선 보완이 필요한 정책 영역 제시
- **언론 모니터링 활용:** 학습한 모델로 일자별 기사에서 정책 영역별 평가 문장만 추려주는 모니터링 보고서 예시 생성
  - 전체 문장 대비 평가 문장 비율을 계산해, 담당자가 읽어야 할 분량이 얼마나 줄어드는지 제시

### 7.6 한계
- 언론 보도는 국민 전체의 인식이 아니라 언론이 선택한 목소리를 반영한다.
- 언론 평가는 실제 정책 효과와 다를 수 있다.
- 본 분석은 보도 내용의 사실 여부를 검증하지 않는다. 출처 신뢰도 필터는 출처 확인 가능 여부만 판단한다.
- 정책 영역 태그는 키워드 규칙 기반이므로 오류가 있을 수 있다.
- 기사 문장의 특성상 중립 문장이 과다하여 긍정·부정 학습 데이터가 부족할 수 있다.
- 정부 보도자료 비중이 높으면 전체 결과가 긍정 쪽으로 치우칠 수 있다.

### 7.7 향후 과제
- 보도 내용의 사실 여부를 판별하는 오보 탐지로의 확장
